# WOOD SCREW PUZZLE

## Project Description
Wood Screw Puzzle is an interactive puzzle game where players remove screws from wooden boards and complete different levels.

## Features
- Login and Signup
- Multiple Puzzle Levels
- Score and Move Tracking
- Game Progress Saving
- Game History
- Leaderboard
- Achievements
- Settings and Daily Rewards

## Technologies Used
- Frontend: React.js, Vite, HTML, CSS, JavaScript
- Backend: Node.js, Express.js
- Database: MongoDB

## Project Structure
- client: Frontend application
- server: Backend application

## Installation
1. Clone the repository.
2. Install dependencies in the client and server folders.
3. Configure the environment variables.
4. Start the frontend and backend servers.

## Security
Do not upload .env files, passwords, or database credentials to GitHub.
